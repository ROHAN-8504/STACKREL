Indian product names arrive in several spellings at once. The same item is
"atta", "aata" or written in Devanagari, and shoppers type all three.
Postgres full-text search treats those as unrelated tokens.

## The hypothesis

Embedding search should collapse those variants, because they sit close
together in vector space regardless of spelling.

## Method

Run both search backends over the DesiStore catalogue with a query set
covering transliteration variants, script mixing and common misspellings,
then compare recall at 10.
