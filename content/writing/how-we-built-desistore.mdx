Every e-commerce prototype starts with fake data, and in India that data is
almost always wrong. Prices in dollars, product names nobody recognises,
categories that do not match how local shops are organised. The demo works
but it does not read as real, and the first thing a stakeholder says is
"why does this look American?".

DesiStore exists to remove that step.

## What it is

A catalogue API shaped like FakeStoreAPI — products, categories, carts,
users — with Indian products, rupee pricing and categories that match the
market. Drop it into a prototype and the data looks right from the start.

## Why not just seed a database

Seeded data goes stale and lives in one project. An API is shared, versioned
and can grow AI features — search that understands intent, descriptions
generated per product — without every consumer re-seeding.
